--- title: Architecture & arborescence nav_order: 4 --- # Architecture générale ## Backend - **Express** (routes REST + pages HTML statiques) - **MongoDB** (sièges, abonnés, saisons, tarifs) - **JWT** (tokens de renouvellement) - **HelloAsso** (Checkout, sandbox/prod) ## Arborescence (extrait) src/ loaders/ express.js # construit l'app Express (CORS, helmet, static, routes) mongo.js # connexion Mongo (MONGO_URI) models/ Seat.js # {seasonCode, venueSlug, seatId, zoneKey, status, provisionedFor} Subscriber.js # abonnés (flat), groupKey, prefSeatId, previousSeasonSeats Season.js # phases (renewal, tbh7, public) Tariff.js # catalogue des tarifs TariffPrice.js # prix par zone/saison/lieu TariffPriceCatalog.js # tarifs catalogue réutilisables (liste zone × tarif) routes/ index.js # routeur principal (inclut /s/renew) renew.js # GET/POST renouvellement admin.js # endpoints admin light (phases, exports, etc.) public/ html/ renew.html # page de renouvellement static/ styles/ renew.css # styles renew venues/ / plan.svg # plan du lieu (servi & parsing SVG) scripts/ 01-venue-management/ register-venue.js import-seats.js import-zones.js validate-svg.js import-tariffs.js export-tariffs.js import-tariff-prices.js export-zone-tariffs.js export-zone-tariffs-matrix.js clone-zone-tariffs.mjs 03-season-management/ upsert-season.js instantiate-venue-for-season.js instantiate-tariffs.js import-renewers-flat.js import-subscription-orders.js provision-season-seats.js renewal-provision-seats.js export-renew-groups.js export-renew-seats.js renewal-close-phase.js renewal-add-subscriber-and-provision.mjs docs/ 04-event-management/ build-allowed-from-prices.js import-qr-bank.js instantiate-tariffs.js send-season-tickets-for-event.js tickets-pdf.js set-onsale.js seats-hold-release.js 05-misc/ orders-import-csv.js orders-delete-csv.js reports/export-orders.js reports/export-seats.js orders-resend-confirmation.js sentinels/pending-orders.js audit-missing-seats.js ## Points clés - **Plan SVG** non stocké en base : servi en statique, parsé côté scripts pour générer le **catalogue de sièges** (collection `seatcatalogs`). - Instanciation par saison → collection **`seats`**. - Les **tokens** de renouvellement contiennent `seasonCode`, `venueSlug`, `groupKey`, `email`, **`seatIds`**.
